# Copilot / Claude instructions — terraform-azurerm-caf-vpn_gateway

This module wraps a single resource: `azurerm_vpn_gateway`. It has no sibling resources (no
private endpoint, no secret/backup/autoshutdown support) because the underlying Azure
resource needs none of those — it always attaches to an existing Virtual Hub
(`virtual_hub_id`), supplied by the caller as a plain input.

## Commands

```bash
terraform init -backend=false
terraform fmt -recursive
terraform validate
terraform test
```

To plan against the ESLZ example (requires a real `virtual_hub_id`, not just mocks):

```bash
cd ESLZ && terraform init && terraform plan -var-file=VpnGateway.tfvars
```

## Naming convention

`{env4}-{group}-{project}-{userDefinedString}-vpng`, lowercased and stripped of any character
not matching `[0-9a-z-]`, truncated to 64 chars total. Implemented in [name.tf](name.tf);
resource group name resolution (accepts either a `resource_groups` map key or a full resource
ID) is in [locals.tf](locals.tf).

## Design patterns present in this module

- Every optional top-level argument uses `try(var.vpn_gateway.<attr>, <registry_default>)`.
- The single optional `bgp_settings` block uses a `dynamic` block gated by
  `try(var.vpn_gateway.bgp_settings, null) != null ? [1] : []`, with two further nested
  `dynamic` blocks for `instance_0_bgp_peering_address` / `instance_1_bgp_peering_address`
  (each optional and independently gated the same way).
- `bgp_settings`/`instance_*_bgp_peering_address` are exported by the provider as sets, not
  lists — any `terraform test` assertion indexing into them needs `tolist(...)` first (see
  `tests/vpn_gateway.tftest.hcl`).
- `tags = merge(var.tags, try(var.vpn_gateway.tags, {}))` — never invent tags, always merge
  the caller's.

## Agent guidance checklist

- Read `variables.tf` → `locals.tf` → the target file before editing.
- Check `ESLZ/VpnGateway.tf` before changing this module's variable interface — it's copied
  verbatim into consuming ESLZ blueprints and must stay in sync.
- Check naming side-effects before changing how `env`/`group`/`project`/`userDefinedString`
  are combined — any change here changes every existing gateway's Azure resource name.
- Keep edits outside the `<!-- BEGIN_TF_DOCS -->` / `<!-- END_TF_DOCS -->` markers in
  `README.md` — that section is regenerated by CI.
- Run `terraform fmt -recursive` after any `.tf` edit.
- Add a new `run` block to `tests/vpn_gateway.tftest.hcl` for any new optional
  argument/block.
